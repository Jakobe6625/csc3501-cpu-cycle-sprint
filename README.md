# CPU Cycle Sprint

A starter prototype for the CSC 3501 Game-Based Learning Project.

## Topic
Fetch–Decode–Execute instruction cycle.

## Learning Objective
After completing the game, the player should be able to distinguish the Fetch, Decode, and Execute stages of the instruction cycle and classify common CPU actions into the correct stage.

## Current Prototype
- Runs directly in a browser.
- Uses HTML, CSS, and JavaScript.
- Gives the player nine CPU-action prompts.
- The player chooses Fetch, Decode, or Execute.
- The game gives immediate feedback and tracks the player's score.
